# Казанский (Приволжский) федеральный университет (КФУ)

- **Полное название:** Казанский (Приволжский) федеральный университет
- **Сокращённое название:** КФУ
- **Город:** Казань
- **Год основания:** 1804 (статус федерального университета — с 2010 года)
- **Тип:** государственный, федеральный университет
- **Ректор:** Ленар Ринатович Сафин
- **Адрес:** 420008, Республика Татарстан, г. Казань, ул. Кремлёвская, д. 18, корп. 1
- **Сайт:** https://kpfu.ru
- **Число студентов:** более 47 000

## Расписание

Единой публичной точки входа по номеру группы для всего университета нет — расписание ведётся
по институтам отдельно, раздел «Студенту → Расписание» на `https://kpfu.ru`:

- `https://kpfu.ru/subject_schedule_web.schedule_type_study` — общий раздел расписания
  (навигация по институту/направлению, без прямого URL-параметра на конкретную группу)
- `https://kpfu.ru/physics/raspisanie-zanyatij` — Институт физики
- `https://kpfu.ru/elabuga/raspisanie` — Елабужский институт (филиал)
- `https://kpfu.ru/chelny/study/timetable` — Набережночелнинский институт (филиал)
