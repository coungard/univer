# Санкт-Петербургский государственный университет (СПбГУ)

- **Полное название:** Санкт-Петербургский государственный университет
- **Сокращённое название:** СПбГУ
- **Город:** Санкт-Петербург
- **Год основания:** 1724
- **Тип:** государственный, классический университет
- **Ректор:** Николай Михайлович Кропачев (с 2015 года)
- **Адрес:** 199034, г. Санкт-Петербург, Университетская наб., д. 7/9
- **Сайт:** https://spbu.ru
- **Число студентов:** более 28 000

## Факультеты и институты

СПбГУ реформировал классическую структуру: часть подразделений называются факультетами, часть —
институтами (в основном образованы позже, на стыке дисциплин). Список собран через агрегатор
postupi.online (страница подразделений):

- **Факультет математики и компьютерных наук**
- **Факультет прикладной математики — процессов управления**
- **Факультет психологии**
- **Факультет социологии**
- **Факультет международных отношений**
- **Факультет политологии**
- **Факультет искусств**
- **Институт химии**
- **Институт философии**
- **Институт педагогики**
- **Институт наук о Земле**
- **Институт когнитивных исследований**
- **Институт развития конкуренции и антимонопольного регулирования**

## Расписание

Общеуниверситетской системы с прямым URL по номеру группы нет — актуальное расписание
публикуется на `https://timetable.spbu.ru/` (навигация по направлению подготовки/факультету, без
параметров URL для конкретной группы) и на `https://edu.spbu.ru` (раздел «Студенту»). Официально
рекомендуемый способ для студентов — мобильное приложение «Кампус», которое подтягивает данные из
этих же источников.
