# Московский государственный университет имени М.В. Ломоносова (МГУ)

- **Полное название:** Московский государственный университет имени М.В. Ломоносова
- **Сокращённое название:** МГУ
- **Город:** Москва
- **Год основания:** 1755
- **Тип:** государственный, классический университет
- **Ректор:** Виктор Антонович Садовничий (с 1992 года)
- **Адрес:** Ленинские горы, д. 1, Москва
- **Сайт:** https://msu.ru
- **Число студентов:** более 38 000

## Расписание

Единого общеуниверситетского расписания у МГУ нет — каждый факультет ведёт своё независимо.
Пример полноценной публичной системы — факультет ВМК:

- `https://cs.msu.ru/studies/schedule` — расписание осеннего семестра 2026/2027 учебного года,
  обновлено 11.09.2026. Группы 101–121, 141–142 (1 курс), 201–220, 241–242 (2 курс), 301–328, 341
  (3 курс), 401–428, 441 (4 курс), 501–528 и 601–628 (специалитет/интегрированная магистратура) —
  расписание каждой группы выложено отдельным PDF на этой странице (актуализируется ежедневно,
  поэтому не выгружаем в этот файл — по клику доступна карта пар/аудиторий на конкретную неделю).
- Аналогичные страницы есть у других факультетов (например,
  `https://math.msu.ru/lesson_schedule`, `https://www.phys.msu.ru/raspisanie-zanyatiy.php`,
  `https://www.journ.msu.ru/study/timetable/`, `http://www.fbm.msu.ru/education/students/schedule/`,
  `https://polit.msu.ru`) — единого расписания и единой точки входа для всего МГУ не существует.
