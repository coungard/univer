# 🎓 University

University — это веб-приложение для управления данными университета: студентами, преподавателями, курсами, лекциями и другими академическими сущностями. Приложение разработано с использованием современных технологий и архитектурных подходов, обеспечивая масштабируемость, безопасность и удобство поддержки.

---

## 🚀 Основные возможности

- Управление университетами, кафедрами, студентами и преподавателями
- Создание и ведение курсов и лекций
- Зачисление студентов на курсы
- Отслеживание посещаемости
- Регистрация студентов через Keycloak
- Полный CRUD через REST API
- Документация API через Swagger UI (OpenAPI 3)
- Безопасность с JWT и OAuth2 через Keycloak
- Миграции базы данных с Flyway
- Пагинация, фильтрация и сортировка

## 📦 Архитектура

Приложение построено по принципам **чистой архитектуры**:
- Слой контроллеров → сервисы → репозитории
- DTO и мапперы для изоляции слоёв
- Конфигурация безопасности через `SecurityConfig`
- Централизованная обработка ошибок (`@ControllerAdvice`)
- Поддержка пагинации и фильтрации

**Тестовый преподаватель** — Ирзаев Г.Х., логин `gamid_teacher_dgtu`, пароль `irzaev123`, роль
`TEACHER`. В отличие от остальных преподавателей в seed-данных (`registered = false`, без Keycloak-

**Тестовые данные для сценариев регистрации** (многошаговая регистрация студента в мобильном
приложении: регион → университет → факультет → курс → группа). Все сущности приходят из seed-миграций,
после пересоздания БД доступны сразу:

| # | Сценарий | Что выбирать |
|---|---|---|
| 1 | в регионе нет университетов | регион «Ненецкий автономный округ» или «Херсонская область» |
| 2 | у университета нет факультетов | Республика Дагестан → «Дагестанский государственный технический университет Филиал в г.Каспийске» (как и большинство филиалов из каталога vuzopedia) |
| 3 | на курсе нет групп | Республика Дагестан → «ДГТУ» → «Факультет компьютерных технологий и энергетики» → курс 2 (группы заведены только на 1 курсе) |
| 4 | у группы нет расписания | тот же факультет → курс 1 → «У539 ТЕСТ (без расписания)» |
| 5 | группа с готовым расписанием | тот же факультет → курс 1 → «У530 РПиС» или «У533 РПиС» |

«Расписание» здесь — занятия (`Lecture`), которые отдаёт `GET /lectures/me`. У групп РПиС они заведены
на весь осенний семестр 2026 миграцией `V31__generate_rpis_lectures.sql`. «У539 ТЕСТ (без расписания)»
— не настоящая группа вуза, а фикстур из `V32__insert_test_group_without_schedule.sql`: у неё нет ни
шаблонов пар (`Pair`), ни занятий, поэтому она остаётся пустой, даже если её студент запустит
генерацию расписания. У «У532 КСиТ» и «У534 СПиКТ» занятий тоже нет, но пары есть — после
`POST /lectures/generate*` расписание у них появится. Группы попадают в выдачу
`GET /groups?facultyId=&yearNumber=`, пока их семестр актуален (01.09.2026–29.12.2026 и далее, пока
не заведён следующий).
